# Musterteile

Zehn STEP-Dateien zum Ausprobieren der App. Sie sind von
`muster-bauen.js` ERZEUGT, nicht aus einem CAD exportiert: echte
Randdarstellung, aber jedes Mass steht im Skript im Klartext. Nichts
daran stammt von einem Kunden.

| Datei | Teil |
|---|---|
| `welle-glatt.step` | Welle, glatt: ⌀40 x 200 |
| `welle-gestuft.step` | Stufenwelle: ⌀50 x 40, ⌀40 x 120, ⌀30 x 40 |
| `buchse.step` | Buchse: ⌀60 x 45, Bohrung ⌀30 durchgehend |
| `lagerbuchse-gestuft.step` | Lagerbuchse: ⌀80 x 25 / ⌀60 x 35, Bohrung ⌀40 |
| `flansch.step` | Flansch: ⌀120 x 18 / ⌀70 x 22, Bohrung ⌀35 |
| `platte-flach.step` | Platte, flach: 200 x 120 x 12 |
| `platte-mit-bohrung.step` | Platte mit Durchgang: 160 x 100 x 15, Bohrung ⌀25 |
| `lagerbock.step` | Lagerbock: 120 x 80 x 60, Bohrung ⌀40 |
| `deckel.step` | Deckel: 90 x 90 x 10, Bohrung ⌀20 |
| `klotz-massiv.step` | Klotz, massiv: 80 x 80 x 80 |

Neu erzeugen: `node muster-bauen.js`
